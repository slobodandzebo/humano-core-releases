# Humano Libre – releases

Installable builds of the **humanolibre.de** website: the plugin **Humano Core** (shop logic for the digital products, later legal texts and invoices) and the Bricks child theme **Humano Libre**.

Each [release](../../releases) has the plugin zip `humano-core-<version>.zip` and the theme zip `humano-<version>.zip`, each with its signature (`.zip.rsig`). The site reads the latest release from here, checks the signatures and shows updates under *Plugins → Updates* and *Design → Themes*.

The source code is maintained in a private repository. Licence: proprietary.
